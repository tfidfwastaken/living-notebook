# AI Engineer World's Fair 2026 — Talk Transcripts

Transcripts extracted from the official AI Engineer (@aidotengineer) YouTube livestreams and session uploads, one plain-text file per talk, formatted for feeding to AI-text-detection tools (e.g. Pangram).

Each file has a 4-line header (title / speakers / event / source video + timestamps) followed by a separator line and the transcript as flowing paragraphs. To send only the spoken text to a detector, drop everything up to and including the `---` separator line.

Notes and caveats:
- Text comes from YouTube auto-captions: no punctuation guarantees, and names/product words are often mis-transcribed (e.g. "Anthropic" as "Antropic").
- Talk boundaries in the livestreams were reconstructed from emcee cues; a talk file may include the emcee's ~2-sentence intro and applause tail.
- Titles/speaker labels were inferred from the transcript itself and may be approximate; the `Source:` line links the exact video and time range for verification.
- `full-day-transcripts/` holds the raw timestamped caption text of each full livestream, in case you want to re-slice.
- `talks/` holds individually uploaded WF2026 session videos (breakout/online-track talks published on the channel around the event).
